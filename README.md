Monorepo con frontend (React + Vite) y backend (Node.js + Express).

## 📁 Estructura
actividad-deportiva-app/
├── frontend/ → React + Vite + Firebase
├── backend/ → Node.js + Express
└── README.md

## 🚀 Instalación

### Frontend
```bash
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm run dev

📡 API
Backend: http://localhost:5000/api/health

Frontend: http://localhost:5173
EOF
