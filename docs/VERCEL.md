# 🚀 Despliegue con Vercel

## Configuración

- Plataforma: Vercel
- Repositorio: https://github.com/JuanECC/actividad-deportiva-app
- Root Directory: frontend
- Framework: Vite
- Build Command: npm run build
- Output Directory: dist
- Variables de entorno configuradas en Vercel

## CI/CD

- Cada push a `main` genera un despliegue automático.
- Vercel genera previews para pull requests.
- El frontend queda disponible públicamente.
